Домашние задания курса «Python для Data Science» (2019) и финальный проект — **прогноз стоимости квартир**.

## Финальный проект: прогноз цены квартиры

[`Final_project.ipynb`](Final_project.ipynb)

**Задача:** по характеристикам квартиры и района (площадь, комнаты, этаж, год дома, экология, социальная инфраструктура — 20 признаков, 10 000 объектов) предсказать цену.

**Что сделано:**
- **EDA** — распределения признаков, поиск выбросов (площадь, этажность, год постройки), корреляции с ценой
- **Очистка данных** — пропуски в `Healthcare_1` (48%) и `LifeSquare` (21%): медиана и восстановление жилой площади через общую; обработка выбросов
- **Подготовка признаков** — бинарное кодирование категориальных признаков
- **Модель** — `RandomForestRegressor`; гиперпараметры подобраны через `GridSearchCV` (в ноутбуке поиск закомментирован, использованы найденные значения)
- **Результат** — R² = 0.73 на валидации, MAE ≈ 28 500

**Что бы я сделал сейчас иначе** (взгляд из 2026 года):
- R² 0.95 на обучении против 0.73 на валидации — заметное переобучение; стоило ограничить глубину деревьев и проверять на кросс-валидации
- Выборки в `train_test_split` перепутаны местами — модель обучалась на 45% данных, а не на 55%
- В функции обработки выбросов есть условие, которое никогда не срабатывает (`Rooms > 5` **и** `Rooms == 0`) — выбросы по комнатам фактически не обработаны
